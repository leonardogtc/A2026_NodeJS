npm - Node Package Manager

NPM é o gerenciador de pacotes do Node.js, ele é utilizado para instalar, atualizar e gerenciar as dependências do projeto.



Instalação de dependências:

npm install <nome_do_pacote>


Remoção de dependências:

npm uninstall <nome_do_pacote>


Atualização de dependências:

npm update <nome_do_pacote>


Listagem de dependências:

npm list


Visualização de dependências globais:

npm list -g
